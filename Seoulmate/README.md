# 🇷🇴 Seoulmate (서울메이트) - 캡스톤 디자인 웹 플랫폼 (v3)

> **"뷰티 프로필 매칭 기술을 적용해 ‘나와 닮은 크리에이터’의 추천 제품을 한 곳에서 실패 없이 구매하게 하는 루마니아 K-뷰티 크리에이터 커머스 플랫폼"**

본 프로젝트는 실제 **[에이블리 모바일 웹(mobile.a-bly.com)](https://mobile.a-bly.com/)**의 디자인 시스템과 사용자 편의 기능을 100% 반영하여 고도화된 웹 애플리케이션입니다.

---

## 🆕 v3 업데이트 편의성 개선 항목

### 1. 🌐 세부 페이지 및 모달까지 100% 전역 영어(EN) 번역 적용
- 상단 `[EN (English) / RO (Română)]` 버튼을 누르면 홈 화면뿐만 아니라 **상품 상세 바텀시트, 뷰티 진단 6문항, Sameday easybox 주문서, CPNP 정품 인증서, 회원가입 폼까지 모든 세부 페이지가 완벽한 영어로 전환**됩니다.

### 2. 🎠 인터랙티브 히어로 배너 슬라이더 (`1 / 4 >`)
- 상단 메인 광고 배너가 정지된 이미지가 아닌 **실제 좌우 화살표 버튼 (`<`, `>`)과 하단 카운터 배지 (`1 / 4 >`) 클릭으로 부드럽게 넘어가는 슬라이더**로 구현되었습니다.
- 4.5초마다 자동으로 다음 배너로 롤링되는 자동 슬라이드 기능 탑재.

### 3. ⬅️ 전역 뒤로가기(Back) 버튼 및 네비게이션 스택
- 홈 이외의 모든 화면(크리에이터 피드, 뷰티 진단, 스토어, 회원가입, 마이페이지) 상단 좌측에 **에이블리 스타일의 뒤로가기 버튼(`‹`)과 현재 페이지 제목**이 표시되어 언제든 이전 화면으로 직관적인 복귀가 가능합니다.

### 4. 📲 가로 스크롤 잘림 없는 슬라이더 (서브탭 & 퀵 카테고리)
- 검색창 밑의 퀵 카테고리 아이콘(진단, 토너, 세럼, SPF, 크림, 클렌저, 메이크업)과 상단 서브 GNB 탭이 모바일 화면 너비에 갇혀 잘리지 않고, **마우스나 터치 스와이프로 부드럽게 넘겨서 볼 수 있는 가로 슬라이더(Smooth Horizontal Scroll Snap)**로 개선되었습니다.

### 5. 🔍 실시간 검색 필터링 & 토스트 알림 피드백
- 상단 검색창에 브랜드나 제품명을 입력하면 아래 상품 목록이 실시간으로 즉시 필터링됩니다.
- 장바구니 담기 또는 찜하기(하트)를 누르면 화면 상단에 플로팅 토스트 메시지(*"Produsul a fost adăugat în coș! / Added to cart!"*)가 뜹니다.

## 🚀 빠른 실행 및 카카오톡 공유
1. 바탕화면 `Seoulmate` 폴더 안의 **`open.bat`** 또는 **`index.html`**을 실행합니다.
2. 카카오톡으로 실시간 링크를 공유하려면 [Netlify Drop](https://app.netlify.com/drop)에 `Seoulmate` 폴더를 드래그 앤 드롭하시면 즉시 모바일 링크가 생성됩니다.
